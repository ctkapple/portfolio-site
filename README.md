# williamdooling.com

Personal portfolio site for **William Dooling** — Product Designer.

*Risk PM by day, game dev by night.*

## What this is

A small static site built around two projects I designed and shipped myself:

- **[bevfantasy.com](https://bevfantasy.com)** — a fantasy football stats platform. Live, with real users.
- **Into the Storm** — a solo-developed roguelite deckbuilder, currently in alpha.

Each case study covers the problem, the design decisions and what changed based on
feedback, and what actually shipped.

The homepage is deliberately not a neutral gallery. Both projects keep their own real
brand palettes rather than being flattened into a single portfolio accent color, and
the site treats itself as a design artifact worth having a point of view about.

## Stack

Plain HTML, CSS, and JavaScript — no framework, no build step. Deployed via GitHub
Pages from `main`.

## Structure

```
index.html              homepage
```
